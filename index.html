1. Bases expliquées avec logique

1.1. JSON

JSON est un format texte pour ranger des infos que l’ordinateur comprend. Ici, on crée une liste d’animaux. Les commentaires expliquent ce que chaque ligne représente. 

[
// Chaque objet représente un animal, avec son nom et son âge
  { "nom": "Chat", "age": 3 }, // clé 'nom' = nom de l'animal, clé 'age' = âge de l'animal
  { "nom": "Chien", "age": 5 }
]

1.2. DOM

Le DOM représente la page HTML. On peut créer, modifier ou supprimer des éléments. Les commentaires expliquent ce que chaque méthode fait et pourquoi on l'utilise. 

// Crée un bloc <div> pour le placer dans la page
document.createElement("div");

1.3. Modules

Les modules permettent de séparer le code en fichiers réutilisables. Les commentaires expliquent ce que chaque export ou import fait. 

// fichier animaux.js : contient des fonctions pour créer des cartes d'animaux
export function createAnimalCard(){...}

// fichier script.js : importe les fonctions depuis le module pour pouvoir les utiliser
import { createAnimalCard } from "./animaux.js";

1.4. Fetch

Fetch sert à aller chercher des données depuis un fichier ou une API. Les commentaires expliquent le flux : envoyer la requête → recevoir la réponse → transformer en objet JS. 

// récupère le fichier JSON des animaux
const res = await fetch("./animaux.json"); // Fetch envoie une requête HTTP pour récupérer le fichier
const data = await res.json(); // transforme la réponse en objet JavaScript utilisable

1.5. map()

map() permet de transformer chaque élément d’une liste en un nouveau format. Les commentaires expliquent le rôle de chaque transformation. 

// extrait les noms de tous les animaux pour créer une nouvelle liste
const noms = animaux.map(a => a.nom); // a = chaque élément du tableau animaux

2.2. domUtils.js

// Crée une carte pour un animal
export function createAnimalCard(animal) {

  // Crée un bloc <article> pour contenir l'animal
  const article = document.createElement("article");
  article.className = "card"; // ajoute la classe CSS 'card' pour le style
  article.dataset.id = animal.id; // stocke l'identifiant pour pouvoir le retrouver plus tard

  // Crée un titre pour afficher le nom
  const h3 = document.createElement("h3");
  h3.textContent = animal.nom; // met le nom de l'animal dans le titre
  article.appendChild(h3); // ajoute le titre dans le bloc article

  // Crée un paragraphe pour afficher l'âge
  const p = document.createElement("p");
  p.textContent = "Âge : " + animal.age + " ans"; // affiche l'âge
  article.appendChild(p); // ajoute le paragraphe dans le bloc article

  // Retourne la carte complète pour pouvoir l’ajouter à la page
  return article;
}

// Fonction pour afficher tous les animaux dans un conteneur
export function renderList(container, animaux) {

  // Vide le conteneur pour ne pas ajouter les animaux plusieurs fois
  container.innerHTML = "";

  // Crée un DocumentFragment pour améliorer les performances
  const fragment = document.createDocumentFragment();

  // Transforme chaque animal en carte et l'ajoute au fragment
  animaux.map(createAnimalCard).forEach(card => fragment.appendChild(card));

  // Ajoute toutes les cartes dans le conteneur en une seule opération
  container.appendChild(fragment);
}

2.3. script.js

// importe les fonctions depuis le module pour créer et afficher les cartes
import { createAnimalCard, renderList } from "./domUtils.js";

// Récupère les éléments HTML pour afficher la liste et gérer la recherche et le tri
const listEl = document.getElementById("list");
const search = document.getElementById("search");
const sortBtn = document.getElementById("sortBtn");

// Initialise les variables
let animaux = []; // liste complète d'animaux
let filtres = []; // liste filtrée en fonction de la recherche
let asc = true; // ordre de tri : true = ascendant, false = descendant

// Charger les animaux depuis le fichier JSON
async function loadData() {
  const res = await fetch("./animaux.json"); // envoie une requête HTTP pour récupérer le JSON
  animaux = await res.json(); // convertit le JSON en tableau JS
  filtres = [...animaux]; // copie de la liste pour le filtrage
  update(); // met à jour l'affichage après chargement
}

// Mettre à jour l’affichage selon la recherche et le tri
function update() {
  const q = search.value.toLowerCase(); // récupère le texte de recherche en minuscules

  // Filtre les animaux selon la recherche
  filtres = animaux.filter(a => a.nom.toLowerCase().includes(q));

  // Trie les animaux selon l'ordre ascendant ou descendant
  filtres.sort((a, b) =>
    asc ? a.nom.localeCompare(b.nom)
        : b.nom.localeCompare(a.nom)
  );

  // Affiche les animaux filtrés et triés
  renderList(listEl, filtres);
}

// Événement de recherche : met à jour la liste à chaque frappe
search.addEventListener("input", update);

// Événement de tri : inverse l'ordre et met à jour le bouton
sortBtn.addEventListener("click", () => {
  asc = !asc; // inverse l'ordre
  sortBtn.textContent = asc ? "Trier A→Z" : "Trier Z→A"; // change le texte du bouton
  update(); // met à jour l'affichage
});

// Lancer l'application au démarrage
loadData();

3. Version React simplifiée

// Composant principal React
function App() {
  // Définition des états : animaux, recherche et tri
  const [animaux, setAnimaux] = React.useState([]);
  const [q, setQ] = React.useState("");
  const [asc, setAsc] = React.useState(true);

  // Chargement des animaux depuis JSON au démarrage du composant
  React.useEffect(() => {
    fetch("./animaux.json")
      .then(res => res.json())
      .then(setAnimaux);
  }, []);

  // Filtrage et tri des animaux selon la recherche et l'ordre
  const filtres = animaux
    .filter(a => a.nom.toLowerCase().includes(q.toLowerCase()))
    .sort((a, b) =>
      asc ? a.nom.localeCompare(b.nom)
          : b.nom.localeCompare(a.nom)
    );

  // Rendu JSX : input de recherche, bouton de tri, et affichage des cartes
  return (
    <div>
      <input value={q} onChange={e => setQ(e.target.value)} /> // input recherche
      <button onClick={() => setAsc(!asc)}>Trier</button> // bouton tri

      {filtres.map(a => (
        <article key={a.id}>
          <h3>{a.nom}</h3> // nom de l'animal
          <p>Âge : {a.age} ans</p> // âge de l'animal
        </article>
      ))}
    </div>
  );
}

5. Théorie React et explications détaillées

5.1. Qu’est-ce que React ?

React est une bibliothèque JavaScript pour créer des interfaces utilisateurs. Elle permet de gérer la vue d’une application de façon **déclarative**, c’est-à-dire que vous décrivez ce que vous voulez voir plutôt que de manipuler le DOM directement.

5.2. Composants

Un composant est une fonction ou une classe qui retourne du HTML (en JSX). Exemple : function App() { return <div>Hello</div>; } Chaque composant peut contenir son propre état et sa logique.

5.3. JSX

JSX est un langage qui ressemble à du HTML mais permet d’écrire du JavaScript à l’intérieur. Exemple : <h3>{a.nom}</h3> affiche le nom de l’animal. Les accolades {} indiquent que l’on insère une expression JavaScript.

5.4. useState

useState crée un état local dans un composant. - `const [animaux, setAnimaux] = React.useState([]);` - `animaux` = valeur actuelle - `setAnimaux` = fonction pour mettre à jour cette valeur Quand on appelle `setAnimaux(nouvelleValeur)`, React **redessine automatiquement le composant**.

5.5. useEffect

useEffect sert à gérer des effets secondaires, comme : - charger des données depuis un fichier ou une API - écouter des événements - mettre à jour le DOM Exemple : React.useEffect(() => { fetch(...).then(...) }, []); Le tableau vide `[]` indique que l’effet se déclenche **une seule fois au montage du composant**.

5.6. map() dans React

map() est utilisé pour créer plusieurs éléments à partir d’un tableau. Exemple : {filtres.map(a => <article key={a.id}><h3>{a.nom}</h3></article>)} - Chaque élément doit avoir un `key` unique pour que React sache **quoi mettre à jour** lors d’un re-render.

5.7. Événements dans React

Les événements sont déclarés directement dans le JSX : - onChange pour détecter la saisie d’un input - onClick pour un bouton Exemple : <button onClick={() => setAsc(!asc)}>Trier</button> Ici, cliquer sur le bouton **inverse l’état `asc`** et déclenche un re-render.

5.8. Flux de données

- Les données viennent du state (`animaux`, `q`, `asc`) - On applique **filtrage et tri** sur ces données - Le JSX est **re-rendu automatiquement** à chaque changement de state

5.9. Avantages par rapport au DOM classique

  • Réactivité : le composant se met à jour automatiquement quand les données changent.
  • Code plus lisible et modulable grâce aux composants.
  • Gestion facile des listes avec map() et des événements directement dans le JSX.
